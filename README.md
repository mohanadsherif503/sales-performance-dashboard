# 📊 Sales Performance Dashboard

An interactive Excel dashboard designed to provide a comprehensive overview of sales performance, customer behavior, and product trends throughout 2023.

## 🚀 Project Overview
This project transforms raw transactional data into a dynamic and visually appealing interactive dashboard. The primary goal is to empower stakeholders with clear, actionable insights regarding revenue generation, regional performance, and customer purchasing habits to support data-driven decision-making.

---

## 🔍 Key Insights & Visualizations
The dashboard provides in-depth analysis across multiple dimensions[cite: 8]:
* **Sales Trend:** A monthly line chart tracking performance fluctuations from January to December[cite: 8].
* **Regional Sales:** Pie chart breaking down revenue across East, North, South, and West regions[cite: 8].
* **Product Performance:** Analyzes revenue generated by Clothing, Electronics, Food, and Furniture categories[cite: 8].
* **Sales Channels:** Compares the proportion of sales originating from Retail versus Online channels[cite: 8].
* **Customer Type:** Donut chart illustrating the split between New and Returning customers[cite: 8].
* **Payment Method:** Horizontal bar chart tracking preferences across Credit Card, Cash, and Bank Transfer[cite: 8].
* **Top Performance:** Highlights the highest-grossing individuals (David, Eve, Bob, Alice, Charlie)[cite: 8].

## 🛠️ Tools & Features Used
* **Microsoft Excel:** Data transformation and interactive visualization[cite: 8].
* **Interactive Slicers:** Enables seamless filtering by Date, Product Category, and Region[cite: 8].
* **Pivot Tables & Charts:** Used to aggregate data and build dynamic visual elements[cite: 8].
